# quant-strategy-workbench
用于量化策略开发与回测的一体化工作台，把策略研究、数据处理、回测执行和绩效分析集中在一个环境中，方便量化研究者快速迭代策略
# 量化策略工作台 · 本地离线版

一个可以**双击打开、断网使用**的量化策略研究与展示工作台。内置 35 条量化策略、完整回测净值曲线、滚动验证、复盘校准、策略对比等数据，无需联网、无需后端服务、无需安装依赖。

> 本项目是原云端应用的**离线快照版本**：所有数据来自生成时的真实快照（截至 2026-10-25），但不会自动更新，不代表实时行情。

## 快速开始

最简单的方式：**直接双击 `index.html`**，用浏览器打开即可使用全部离线功能（推荐 Edge / Chrome）。

也可以选择本地服务方式（需本机安装 Python 3）：

```bat
双击 start.bat
```

它会启动一个本地服务并自动打开 `http://localhost:8753/`。此方式下，你在模拟盘和自定义策略里的改动会额外落盘到 `store.json`，刷新不丢。

## 功能一览

内置 12 个页面，全部可离线浏览：

| 页面 | 说明 |
| --- | --- |
| 今日结论 | 基于样本外适配度排名合成的「离线适配指数」 |
| 策略库 | 35 条策略的完整档案与参数 |
| 自定义策略 | 查看 / 复制 / 改名 / 启停 / 删除（本地保存） |
| 智能推荐 | 按资金与偏好给出的策略推荐 |
| 回测详情 | 35 份完整回测：净值、回撤、年度 / 月度收益与各项指标 |
| 滚动验证 | 策略的滚动窗口验证结果 |
| AI 资讯预测 | 快照资讯与预测观点 |
| 复盘校准 | 历史复盘与校准数据 |
| 策略适配 | 不同市场环境下的策略适配度 |
| 模拟盘 | 内置示例账户查看 |
| 策略对比 | 多策略并排对比 |
| 研究视图 | 策略相关性、家族聚类、组合构建（等权 / 逆波动 / 最小方差 / ERC）、样本外冻结段等，**由内置净值序列本地实算得出** |

## 数据与精度说明

- 所有行情、资讯、回测均为**生成快照时的真实冻结数据**（截至 2026-10-25），不是实时数据，界面顶部已标注「离线快照」。
- 「今日结论」使用内置的样本外适配度排名归一化为「离线适配指数」，并非云端六维实时综合分。
- 研究视图中的相关性矩阵、有效独立策略数、组合风险收益指标、样本外冻结段结构，均由内置净值序列在浏览器本地计算得到，数值真实可复现。
- 依赖云端计算引擎的功能（如预测重算、自然语言建策略、一键刷新行情等）在离线版本中有明确提示，不会返回虚构数字。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `index.html` | 应用主体，单文件包含全部界面、样式与数据层，双击即可运行 |
| `data.json` | 从原应用提取的完整快照数据（策略、回测、资讯、复盘等） |
| `server.py` | 可选的本地后端（纯 Python 标准库），提供 `start.bat` 方式下的 API 与数据落盘 |
| `start.bat` | 一键启动本地服务并打开浏览器 |
| `.gitignore` | 排除运行时个人数据与缓存 |
